## MyScoutee Registry 1.0.0 — QA Preview 1

This prerelease provides the first packaged Debian deployment of the standalone MyScoutee Registry for integration and qualification testing.

### Included

- MyScoutee Registry API
- TLS-enabled nginx edge
- Docker Compose deployment
- systemd service integration
- Bundled production container images
- Registry client and operator tools
- SHA-256 checksum files for release artifacts

### Artifacts

- `myscoutee-registry_1.0.0-qa.1_amd64.deb`
- `myscoutee-registry_1.0.0-qa.1_amd64.deb.sha256`
- `myscoutee-registry-client-tools_1.0.0-qa.1.tar.gz`
- `myscoutee-registry-client-tools_1.0.0-qa.1.tar.gz.sha256`

The Debian package contains the required production container images; no separate image download is required.

### Validation completed

- Fresh Debian package build
- Package contract checks
- Docker build-context and nginx image checks
- Installation and reinstall on a clean VMware target
- systemd startup and controlled restart
- Container health checks
- HTTPS `/healthz` and `/versionz` smoke tests
- Host qualification for version `1.0.0`

sha256sum -c myscoutee-registry_1.0.0-qa.1_amd64.deb.sha256

### QA package identity correction — 2026-09-17

The artifacts now use package version `1.0.0-qa.1` (Debian `1.0.0~qa.1`) so stable `1.0.0` sorts newer. Original downloads and their SHA-256 values were retained before replacement. The two original container image IDs and all image config/layer bytes are unchanged; only archive tags and packaging metadata were relabelled. The historical Registry binary still reports build version `1.0.0`; the packaged host qualifier verifies that original binary version separately from the QA package version. This is a packaging correction, not a new Registry implementation or a new runtime qualification. The original qualification above applies to the original artifacts.

This historical prerelease retains tag `v1.0.0-qa.1`. The newly built stable
package is a separate release: [MyScoutee Registry 1.0.0](https://github.com/fssrepository/myscoutee-registry/releases/tag/v1.0.0).
