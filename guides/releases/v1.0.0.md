# MyScoutee Registry 1.0.0

Stable Debian release for amd64, following `v1.0.0-qa.1`.

## Included

- Standalone Registry API and TLS nginx edge.
- Docker Compose deployment, systemd integration and two bundled production images.
- Operator client tools, SHA-256 sidecars and Ed25519 artifact signatures.
